\# NAVE — Curadoria Pedagógica ENEM



Aplicação web para curadoria pedagógica de questões do ENEM.



\## Projeto



NAVE — Núcleo de Aprendizagem, Valor e Estratégia



\## Funcionalidades atuais



\- busca e visualização de questões;

\- cadastro manual;

\- filtros por área, disciplina, competência e habilidade;

\- sequências pedagógicas;

\- validação docente;

\- governança pela coordenação;

\- usuários e permissões;

\- projetos editoriais;

\- geração de pacotes para editoração;

\- integração com RStudio para geração dos cadernos.



\## Tecnologias



\- Google Apps Script

\- Google Sheets

\- HTML / CSS / JavaScript

\- clasp

\- Git

\- GitHub

\- R / RStudio
